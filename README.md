# FinalCal plugins

Calendar tools for Claude and ChatGPT, backed by the hosted FinalCal MCP service at https://finalcal.com/mcp. Sign in with Google through FinalCal and choose read or write access.

- `claude/`: Claude plugin source. Directory submissions use plugin path `claude` on the `main` branch.
- `chatgpt/`: ChatGPT plugin source, including the OAuth configuration and proposed review cases.

Directory publication is pending. This repository contains distribution packages only; the hosted application's source and credentials are not included.

Documentation: https://finalcal.com/docs/mcp/
Support: https://finalcal.com/support/
Privacy: https://finalcal.com/privacy/
